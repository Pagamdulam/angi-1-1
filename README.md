# Хэрэглээний программ 1-1 · Эцэг эхийн булан

## GitHub Pages дээр байршуулах
1. github.com → **New repository** → нэр: `angi-1-1` → Public → Create.
2. **Add file → Upload files** → `index.html` ба `og.png` хоёрыг чирж оруулаад Commit. (`og.png` нь FB-д холбоос хуваалцахад гарах зураг.)
3. **Settings → Pages → Branch: main / root → Save.**
4. 1–2 минутын дараа: https://pagamdulam.github.io/angi-1-1/

## Засах
`index.html` файлын доод хэсэгт `БАГШ ЭНД ЗАСНА` гэсэн хэсэг бий:
- `MESSENGER` — Messenger холбоос (жишээ: https://m.me/таны.хаяг)
- `PHONE` — утасны дугаар
- `ANN` — зар (шинийг хамгийн дээр нэмнэ)
- `EVENTS` — чухал өдрүүд

GitHub дээр файлаа нээгээд ✏️ (Edit) дарж засаад **Commit changes** дарахад хангалттай.

⚠️ Хүүхдийн нэр, дүн, ирц, утасны дугаар зэрэг хувийн мэдээлэл оруулахгүй.
